1. ARCHITECTURE BLUEPRINT & METRICS
------------------------------------------------------------------------------
The system suppresses stationary (hiss), non-stationary (sirens), and impulsive (gunfire) noises with sub-20ms latency.

* Sampling Rate: 16,000 Hz
* STFT Params: N_FFT = 512, Hop Length = 256
* ML Model: U-Net Convolutional Neural Network estimating an Ideal Ratio Mask (IRM).
* Loss Function: Compressed Power Loss (Magnitude^0.5).
* Target Metrics: > 15 dB SNR Gain, > 0.85 STOI, < 20 ms Algorithmic Latency.

4. RECENT CRITICAL UPGRADE (DO NOT REVERT)
------------------------------------------------------------------------------
We recently replaced a static vocal boost (2.8x) with a **Tactical Automatic Gain Control (AGC)** in `inference.py` and `realtime_demo.py`. 
* WHY: If a soldier screams on the battlefield, a static multiplier causes violent digital clipping when it hits the `np.tanh` soft-clipper.
* HOW IT WORKS: 
  `peak_energy = np.max(mag_frame * final_mask)`
  `safe_limit = 12.0`
  `dynamic_boost = safe_limit / (peak_energy + 1e-6) if peak_energy > safe_limit else 2.8`
* ACTION: Ensure all future DSP modifications respect this AGC logic to protect squad hearing.
